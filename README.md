# Auspify Finance Internship – Task Submission

4-week remote Finance internship by **Auspify Technologies**. This repository contains four completed tasks, each built as an Excel workbook with live formulas.

| # | Task | Level | File |
|---|------|-------|------|
| 1 | Personal Budget Planner | Easy | `Task1/Task1_Personal_Budget_Planner.xlsx` |
| 2 | Loan EMI Calculator | Easy | `Task2/Task2_Loan_EMI_Calculator.xlsx` |
| 3 | Stock Market Analysis Report | Medium | `Task3/Task3_Stock_Market_Analysis_Report.xlsx` |
| 4 | Financial Ratio Analysis (TCS) | Medium | `Task4/Task4_Financial_Ratio_Analysis_TCS.xlsx` |

## Task summaries

**Task 1 – Personal Budget Planner.** Income tracking, categorised expenses (Need / Want / Savings), monthly budget sheet, savings rate, 50/30/20 rule check and spending-habit insights with charts.

**Task 2 – Loan EMI Calculator.** Inputs: loan amount, interest rate, tenure. Outputs: monthly EMI, total payment, total interest, full amortization schedule (up to 30 years), seven test scenarios, and a cross-check of Excel's PMT against the manual EMI formula.

**Task 3 – Stock Market Analysis Report.** Return, volatility, Sharpe ratio, beta, drawdown and trend analysis for five NSE companies versus Nifty 50, plus a fundamentals comparison and a composite ranking.
> ⚠ Replace the sample data in the `Data Input` sheet with real prices before relying on results.

**Task 4 – Financial Ratio Analysis.** TCS FY2026 vs FY2025 (consolidated, Ind AS): profitability, liquidity, solvency, efficiency ratios, DuPont analysis and a written interpretation. Source: TCS investor-relations filings.

## How to use
1. Open a workbook in Microsoft Excel or LibreOffice Calc.
2. Edit only the **blue** cells (inputs); black cells are formulas and green cells link to other sheets.
3. Everything recalculates automatically.
